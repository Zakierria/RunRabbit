Run Rabbit

Run Rabbit is a 3D survival horror game inspired by games like Granny. Players must explore a house, interact with objects, solve environmental puzzles, and find a way to escape while avoiding danger.

The game focuses on exploration, puzzle-solving, interactive environments, and suspenseful gameplay.

Game Overview

Genre: 3D Survival Horror

Engine: Godot 4.6.2

Development Tools: Godot, Itch.io, TrenchBroom, FuncGodot

Programming Language: GDScript

Platform: PC

 Features

3D low-poly horror environment.

Multi-level house with different rooms and areas to explore.

Interactive objects throughout the environment.

Animated doors and furniture interactions.

Fuse box interaction and puzzle mechanics.

Environmental exploration and puzzle-solving.

Escape objective and ending screen.

Main menu and win screen functionality.

Getting Started

To open and run the project locally:

Download or clone this repository.

Install Godot Engine.

Open Godot.

Select Import.

Navigate to the downloaded project folder.

Select the project.godot file.

Open the project and press F6 or F5 to run the game.

Project Goal

The goal of Run Rabbit is to create an immersive horror experience where players must explore their surroundings, interact with objects, overcome obstacles, and discover a way to escape.

This project provided hands-on experience with 3D game development, level design, collision detection, animation systems, interactive object scripting, and collaborative software development.

Developed as a group game programming project at Georgia Southern University.
